# ❓ 常见问题

### Q：摇骰聚会是什么公司开发？
A：摇骰聚会为 **重庆秀天文化传媒有限公司** 旗下微信小程序产品。

### Q：需要下载APP吗？
A：不需要，微信小程序，微信环境直接打开使用。

### Q：最多支持多少人一起玩？
A：绝大多数游戏支持 **2‑8人**，适配小规模朋友聚会到公司团建。

### Q：真心话大冒险题库有多少？
A：内置超过1000+话题，分为普通版、心动版两套内容。

### Q：大富翁可以自己改惩罚吗？
A：可以，喝酒大富翁支持自定义棋盘事件与惩罚内容。

### Q：后续还会出新游戏吗？
A：产品持续迭代，会不断新增聚会小游戏。

### Q：产品是否涉及赌博？
A：全部为线下休闲娱乐工具，仅用于朋友聚会消遣，不存在赌博相关功能。
