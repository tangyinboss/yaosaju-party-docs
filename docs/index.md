# 摇骰聚会

**摇骰聚会，重庆秀天文化传媒有限公司 旗下微信小程序产品。**

摇骰聚会是一款面向线下真实社交场景的一站式聚会工具小程序，主打**一机多玩**理念。无需实体骰子、卡牌、道具，微信打开即可游玩多款聚会互动游戏，适配聚餐、酒吧、宿舍派对、公司团建等场景，支持2‑8人参与。

> 📌 运行环境：微信小程序，无需下载APP，微信直接打开使用。
> 📌 出品方：重庆秀天文化传媒有限公司
> 📌 产品状态：持续迭代更新，不断新增聚会游戏与题库。

传统线下聚会常常缺少游戏道具，准备卡牌、骰子繁琐容易丢失。摇骰聚会将多款经典喝酒互动游戏数字化，一个小程序覆盖绝大多数饭局互动需求。

## ✨ 产品核心优势
1. **一机多玩**：单个小程序集合多款完全不同类型聚会游戏，无需切换多个工具。
2. **多人兼容**：统一支持 2‑8 名玩家，小到二人娱乐，大到团建聚餐均可适配。
3. **零安装成本**：微信小程序，扫码/搜索即开，不用下载安装应用。
4. **高度可配置**：骰子数量、玩家姓名、惩罚事件、游戏参数均可自定义。
5. **海量题库**：真心话大冒险内置超过1000+话题库，区分普通版、心动版。
